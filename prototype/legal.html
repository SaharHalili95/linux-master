אין קשר לגופי ההסמכה

Linux Master הוא פרויקט עצמאי של סהר חלילי. הוא לא קשור ל-LPI, Red Hat, Linux Foundation, SUSE, CompTIA או OverTheWire, והם לא אישרו או מימנו אותו. השמות LPIC-1, Linux Essentials, RHCSA, LFCS, SUSE ו-CompTIA Linux+ הם סימנים של בעליהם, ומופיעים כאן רק כדי לתאר לאיזו הסמכה התוכן עוזר להתכונן.

אין הבטחה לעבור מבחן

הקורס נועד ללימוד ולתרגול. מבחני הדמה נכתבו לפרויקט הזה, הם לא שאלות אמיתיות מהמבחנים, והציון בהם לא מנבא את התוצאה במבחן הרשמי. התוכן ניתן כמו שהוא, ועלולות ליפול בו טעויות. לפני שמריצים פקודה על מערכת אמיתית כדאי להבין מה היא עושה.

פרטיות

  • אין צורך בהרשמה, ואין באתר כלים למעקב או לפרסום.
  • ההתקדמות נשמרת רק בדפדפן שלך. אפשר לשמור גיבוי לקובץ, ואפשר לאפס אותה בכל רגע.
  • האתר מאוחסן ב-GitHub Pages, ומצב הטריוויה טוען גופנים מ-Google Fonts. השירותים האלה מקבלים את כתובת ה-IP שלך כמו בכל טעינת אתר.
  • כפתור הדיווח על בעיה פותח דיווח ב-GitHub. הוא גלוי לכולם, ונשלח רק אם בחרת לשלוח אותו.

נגישות

האתר בנוי לשימוש במקלדת ובקוראי מסך, ועם תמיכה בעברית מימין לשמאל. בכל שינוי רצות בדיקות נגישות אוטומטיות. לא בוצע מבדק ידני מלא, ולכן ייתכן שיש דברים שפספסנו. נתקלת בבעיה? אפשר לכתוב אל סהר חלילי, איש הקשר לנגישות: sahar_halili@icloud.com.

The course is for learning and practice. The mock exams were written for this project, they are not real exam questions, and their scores don't predict your result in the official exam. The content is provided as is and may contain mistakes. Make sure you understand a command before you run it on a real system.

Privacy

  • You don't need to sign up, and the site has no tracking or advertising tools.
  • Your progress is saved only in your browser. You can save a backup file and reset your progress at any time.
  • The site is hosted on GitHub Pages, and Trivia mode loads fonts from Google Fonts. These services receive your IP address, as with any page load.
  • The report button opens an issue on GitHub. It is public and is sent only if you choose to send it.

Accessibility

The site is built for keyboard and screen reader use, with right-to-left support in Hebrew. Automated accessibility tests run on every change. It has not had a full manual audit, so we may have missed something. If you run into a problem, write to Sahar Halili, the accessibility contact: sahar_halili@icloud.com.
