# Linux Master

מדריך לימודי בעברית לפקודות לינוקס, עם אזור הדרכות וטריוויה בלבד. מסלול הלימוד מתקדם בשבעה שלבים: פקודות, שימושים מתוך המדריך, צינורות, צינור עם דגל, תרגול מקצועי, צינור עם כמה דגלים ותהליכי עבודה. שלב הפקודות כולל 46 פקודות, ושלב השימושים כולל את כל 450 רשומות השימוש שחולצו ממדריך Bandit. כל אחד מחמשת השלבים המעשיים כולל 15 תרחישים. התרגול מחולק לסבבים של עד 20 שאלות, וההתקדמות בכל שלב נשמרת אחרי כל תשובה, כך שאפשר לצאת באמצע ולהמשיך מאותה נקודה. אחרי כל תשובה מוצג הסבר, והמשחק עובר אוטומטית לשאלה הבאה לאחר חצי שנייה.

**לאתר:** https://saharhalili95.github.io/linux-master/

## פרסום ב-GitHub Pages

ה-workflow שב-`.github/workflows/pages.yml` מפרסם את האתר אוטומטית בכל push לענף `main`. ב-GitHub יש לבחור **Settings → Pages → Build and deployment → GitHub Actions**. כתובת האתר: `https://saharhalili95.github.io/linux-master/`.

## התקנה באייפון

1. לפתוח את כתובת האתר ב-Safari.
2. לבחור **שיתוף → הוספה למסך הבית**.
3. להפעיל **פתיחה כיישום רשת** ולבחור **הוספה**.

המשחק שומר את הניקוד וההתקדמות במכשיר (localStorage), בלי שרת ובלי חשבון. טעינה ראשונה דורשת חיבור לאינטרנט; לאחריה קובצי המשחק נשמרים לשימוש ללא רשת.
